Changelog

Changes agents made to the system and to projects. Each entry says how to undo it.

Rules

Every rule the agents follow. Untick a rule to turn it off everywhere: it leaves the managed CLAUDE.md and the prompts, and if it is a hub behaviour it stops at once. Text rules apply from the agent's next start. Every change is logged in the Changelog and Brain is told.

Jobs

Every job is a card: who has it, its state, the last step, the next step, tokens spent and its budget. The agent updates the card at every step, no need to ask. Stuck? = no step written for 30+ minutes. Unassigned = spend today not tied to any job.

Queue

Everything waiting right now: messages that have not reached their agent yet (the hub queue and the agent's own inbox), agents waiting to wake, upcoming tasks and how long running turns have taken. Stuck? = the turn is running but has written nothing for 20+ minutes.
